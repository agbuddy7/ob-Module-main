🔒 Image Scrambler Extension Test Page

How to Test:

  1. Install the extension from the extension folder
  2. Enable file URL access:
    • Go to chrome://extensions/
    • Find "Image Scrambler"
    • Click "Details"
    • Turn ON "Allow access to file URLs"
  3. Create a scrambled image using the button below
  4. Open browser console (F12) to see extension logs
  5. Look for 🔒 messages in console to see what the extension is doing
