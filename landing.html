What Is Image Scrambler?

Image Scrambler is a powerful browser extension that protects your images from unauthorized AI training and web scraping. It intelligently scrambles images (especially faces) making them unusable for AI models, while allowing legitimate users to automatically view the original content.

Smart Face Detection: Automatically detects faces in images and scrambles only the face region, leaving the rest of the image untouched. If no face is detected, it scrambles the entire image as a fallback.

How to Install the Extension

  1. Download the Extension Download or clone the extension files from the repository to your computer.
  2. Open Chrome Extensions Open Google Chrome and navigate to chrome://extensions/
  3. Enable Developer Mode Toggle the "Developer mode" switch in the top-right corner.
  4. Load Extension Click "Load unpacked" button and select the extension folder from the downloaded files.
  5. Start Using! Click the extension icon in your browser toolbar to start scrambling images.

How to Use

Scrambling Images:

  1. Click Extension Icon Click the Image Scrambler icon in your browser toolbar.
  2. Upload Image Click "Choose File" or drag-and-drop an image into the extension popup.
  3. Scramble Click "Scramble Image" button. The extension will:
    • Try to detect faces using AI (API-based)
    • If face found → scramble only the face region
    • If no face → scramble entire image
  4. Download Download the scrambled image and share it anywhere!

Viewing Scrambled Images:

The extension automatically detects and unscrambles protected images on any website you visit. No action needed!

Automatic Protection: Once installed, the extension runs in the background and automatically unscrambles any protected images you encounter while browsing.

How It Works

Scrambling Process:

  • Face detection API analyzes the image
  • If face detected: extracts face bounding box region
  • Divides region into 8×8 pixel tiles
  • Randomly shuffles tiles using cryptographic PRNG
  • Embeds detection marker and seed in image
  • If no face: scrambles entire image as fallback

Unscrambling Process:

  • Automatically detects scrambled images on webpages
  • Extracts embedded seed from marker column
  • Reverses tile shuffle using same PRNG algorithm
  • Verifies correctness with embedded validation data
  • Displays original image seamlessly

Requirements

  • Google Chrome or Chromium-based browser (Edge, Brave, etc.)
  • Internet connection (for face detection API)
  • No additional software or dependencies needed
